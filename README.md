## 📖 專案簡介 (Overview)
**WanderVibe 漫步時光** 是一款專為美學愛好者、設計師與城市漫遊者打造的「一日行程規劃與預算計算小工具」。
本專題依循課程核心理念 **AI Agent Vibe Coding**，透過自然語言指導 AI Agent 進行系統架構規劃、互動體驗設計、動態資料管理與視覺美學打磨。

使用者可直覺地瀏覽預設精選一日行程（以「台北文青設計散策：大稻埕與赤峰街」為範例），亦能自由新增、編輯、刪除或拖曳調整各站順序；系統會即時重新計算整日時間軸、預估總費用、各類別支出佔比，並同步於互動式地圖（Leaflet Map）標記停靠路徑與提供多人均攤分帳功能。

## 🌟 核心功能特色 (Key Features)

### 1. 一日行程視覺化時間軸（One-Day Visual Timeline）
- **時間與順序流動**：依序呈現 `09:30 - 21:00` 的流暢一日行程。
- **類別標籤系統**：區分「美食咖啡 🍜」、「歷史人文 🏛️」、「設計藝文 🎨」、「風格選品 🛍️」、「交通散步 🚶」。
- **即時時間計算**：輸入各景點停留時長後，自動計算預計結束時間與下一站抵達時間。

### 2. 資料管理 CRUD 功能（滿分加分項：+10分）
- **Create（新增）**：自訂行程名稱、分類、開始時間、停留分鐘、預估花費、座標與亮點筆記。
- **Read（檢視與篩選）**：依類別即時篩選（美食/藝文/選品/全部），支援地圖聚焦定位。
- **Update（編輯修改）**：點擊編輯按鈕即可即時修改內容；支援 **Sortable 拖曳排序**，拖動景點卡片後自動依順序校準全天時間軸！
- **Delete（刪除）**：一鍵移除行程項目，系統防呆確認後自動重新計算總花費與時長。
- **LocalStorage 保存**：免登入、無伺服器負擔，修改即刻持久化保存在瀏覽器。

### 3. 動態預算與佔比重算（Live Budget Recalculation）
- 隨著景點增刪或費用修改，即時計算：
  - 當日總預算花費 (NT$)
  - 總活動時長（包含景點停留與每站間 15 分鐘交通緩衝）
  - 預估步行總步數
  - 支出分佈彩色進度條與類別佔比統計（餐飲咖啡、門票藝文、風格選品、交通車資）

### 4. 互動地圖路線導引（Interactive Map with Leaflet）
- 整合 OpenStreetMap 與 Leaflet.js，以設計感標記依序標註各站點。
- 景點間自動繪製路線導引虛線，點擊卡片定位圖示可平滑飛入（Fly-to）該景點座標並彈出資訊。

### 5. 多人分帳計算小工具（Split Bill Calculator）
- 支援 1～20 人彈性設定。
- 即時連動當前行程總花費，自動計算每位同行者應分攤金額。

## 🛠️ 期末簡報必備：三項實際改善紀錄（3 Changes Log）
依據課程規格要求，上台報告簡報最後需呈現至少 3 項真實改善（原問題 ➔ 怎麼改與原因 ➔ 如何驗證）：

### 改善紀錄 1：行程排序調整後的時間衝突與斷點問題
- **原問題**：使用者在拖曳卡片調整景點先後順序後，各項目的「抵達時間」仍停留在原本填寫的時間，導致時間軸順序顛倒混亂（例如下午的行程跑到上午）。
- **怎麼改與原因**：在 `app.js` 中實作 `recalculateSequentialTimes()` 邏輯。當 Sortable 拖曳完成或點擊「依序校準時間」時，系統以第一站為基準，根據每站停留時間並自動加入 15 分鐘轉乘緩衝，循序重新推算各站的時間。
- **如何驗證**：將最後一站「寧夏夜市」拖曳至第二站，觀察時間軸是否立即由 18:30 動態重新排入 10:45 區段，後續行程亦同步順延，不再發生時間倒流。

### 改善紀錄 2：費用修改後統計圖表未能即時反應佔比
- **原問題**：初期版本僅計算總金額數字，但對於商業設計系的視覺呈現而言，使用者無法一目了然看出品味消費中「咖啡餐飲」與「展覽選品」的預算佔比。
- **怎麼改與原因**：引入類別費用累加字典與動態 CSS 寬度百分比進度條（`#budgetProgressBar`），每當執行 CRUD 操作時呼叫 `recalculateAnalytics()`，將餐飲、門票、購物、交通以專屬色彩比例呈現。
- **如何驗證**：編輯「Modern Mode 老件選物咖啡」，將費用由 380 改為 800，儲存瞬間總預算由 1,280 變更為 1,700，且黃色餐飲佔比條平滑延長至 50% 以上。

### 改善紀錄 3：手機版小螢幕下地圖與卡片排版擁擠
- **原問題**：在手機或窄螢幕平板檢視時，地圖與時間軸並排導致文字被嚴重擠壓、操作不易。
- **怎麼改與原因**：採用 Tailwind CSS 響應式斷點設計（`grid-cols-1 lg:grid-cols-12`），在大螢幕維持左 7 右 5 黃金比例，在行動裝置上則自動重構為上下垂直單欄，並將導覽列按鈕文字收合為直覺 Icon。
- **如何驗證**：透過 Chrome 開發者工具切換 iPhone 14 / iPad 視窗解析度測試，確認無論在手機直立或電腦橫向操作，時間軸滑動、地圖縮放與 Modal 彈窗均無任何跑版或破圖現象。

## 🚀 部署上線教學（Deploy to Vercel）
1. 在 GitHub 上建立一個新的公開 Repository（例如 `wandervibe-trip-planner`）。
2. 將本專案的所有檔案（`index.html`、`app.js`、`styles.css`、`vercel.json`、`README.md`）提交（Commit）並推送（Push）到 GitHub。
3. 前往 [Vercel 官網](https://vercel.com/)，以 GitHub 帳號登入。
4. 點擊 **"Add New Project"**，選取剛建立的 GitHub Repo。
5. 架構 Framework 選擇 **"Other"**（靜態網站），直接點擊 **"Deploy"**。
6. 約 30 秒內即可獲得專屬公開網址（如 `https://wandervibe-planner.vercel.app`）！
